# Linux Skill

## Purpose

Allow LocalEngineer to work with the local Linux environment.

## Capabilities

- Inspect files and directories
- Read and modify project files
- Run development commands
- Inspect processes
- Inspect installed software
- Run tests

## Safety

Do not blindly execute destructive commands.

Require confirmation before:

- Deleting important files
- Formatting disks
- Changing system configuration
- Installing potentially unsafe software
- Running commands with elevated privileges

Never expose credentials, private keys, or secrets.
