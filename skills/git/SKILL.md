# Git Skill

## Purpose

Allow LocalEngineer to work with Git repositories.

## Capabilities

- Inspect repository status
- Inspect commits
- Review diffs
- Create branches
- Create commits
- Work with remotes
- Push changes when authorized

## Safety

Before committing, inspect the diff.

Never commit:

- API keys
- Passwords
- Private keys
- Tokens
- .env files
- Authentication cookies

Do not force-push unless explicitly authorized.
