# LocalEngineer

Local AI engineering agent.

Architecture:

- OpenAI = reasoning/model
- Brave = browser agent
- CDP = browser control
- Skills = agent capabilities
- Tools = local computer capabilities
- Git = source control
- SQLite = local state
- Docker = optional sandbox

## Directories

apps/       Application code
packages/   Shared packages
skills/     Agent skills
tools/      Local tools
projects/   User projects
sessions/   Agent sessions
memory/     Agent memory
config/     Configuration
